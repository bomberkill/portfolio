# Prompt pour génération de logo (IA)

Voici un prompt détaillé conçu pour générer un logo professionnel, moderne et adapté à votre esthétique "Cosmic Glass" / "Clean Tech".

## Le Prompt (Copiez-collez ceci)

> **Sujet** : Logo minimaliste et futuriste pour un développeur Full Stack nommé "Ronald".
>
> **Symbole central** : La lettre "R" stylisée ou un monogramme abstrait combinant des formes géométriques fluides.
>
> **Style "Cosmic Glass" (Dark Mode)** :
> *   **Effet** : Glassmorphism, translucidité, bords lumineux (neon glow).
> *   **Couleurs** : Dégradé profond de Violet (#8b5cf6) à Cyan (#0ea5e9) sur fond sombre (Deep Space).
> *   **Détails** : Une légère lueur interne, finition brillante, aspect "tech" et premium.
>
> **Style "Clean Tech" (Light Mode Version)** :
> *   Le même logo doit être lisible en silhouette sombre (Slate Blue) sur fond blanc.
>
> **Composition** :
> *   Design vectoriel, centré, ratio 1:1.
> *   Pas de texte complexe, juste l'initiale ou l'icône.
> *   Rendu 3D isométrique subtil ou "Flat 2.0".
>
> **Mots-clés additionnels** : Cyberpunk soft, Elegant, Coding, Digital Art, 8k resolution, Unreal Engine 5 render style.

## Conseils pour l'outil (Midjourney / DALL-E / Nano Banana)
*   Si le résultat est trop chargé, ajoutez : `--no text --no realistic details --minimalist`.
*   Pour obtenir un fond transparent, précisez : `white background` ou `solid black background` pour pouvoir le détourer facilement ensuite.
